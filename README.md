# rugby-match-scorer

A live rugby match scoring application with spectator view, real-time timers, and match event tracking.

## Features

- **Scorer Tab**: Live match scoring with configurable half durations
- **Fixtures Tab**: Create and manage match fixtures
- **Spectator Tab**: View live matches with real-time updates
- **Event Tracking**: Automatic logging of all scoring events with timestamps
- **Responsive Design**: Mobile-friendly dark theme interface
- **Real-time Timer**: Match timer with automatic half-time and full-time detection

## Scoring Options

- **Try**: 5 points
- **Conversion**: 2 points
- **Penalty Goal**: 3 points
- **Drop Goal**: 3 points
- **Point Removal**: Undo scoring errors

## Usage

1. Go to the **Fixtures** tab to create a new match
2. Enter team names, date, kick-off time, and half duration
3. Switch to **Scorer** tab and select the fixture
4. Start the timer and begin scoring
5. Share the **Spectator** link with viewers to watch live

## Technologies

- HTML5
- CSS3 (Dark theme with custom properties)
- Vanilla JavaScript (No dependencies)
- Tabler Icons for UI icons
